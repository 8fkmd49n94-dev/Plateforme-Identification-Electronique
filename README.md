# Plateforme d'Identification Électronique

## Présentation

Projet de fin d'études (PFE) portant sur la conception et la réalisation d'une application web dans le domaine de l'identification électronique.

## Objectif

Développer une solution numérique visant à renforcer la sécurité des processus d'identification et d'authentification.

## Technologies utilisées

- Java
- Spring Boot
- React.js
- Python
- FastAPI
- PostgreSQL

## Confidentialité

Ce projet a été réalisé dans un cadre académique et professionnel.

Pour des raisons de confidentialité, le code source et les détails techniques de l'application ne sont pas publiés.
